## Comment ajouter vos images

1. Téléchargez vos images
2. Placez-les dans le dossier `public/`
3. Les images seront accessibles directement via `/nom-de-l-image.ext`

Exemple : `public/desert.jpg` sera accessible via `/desert.jpg`
